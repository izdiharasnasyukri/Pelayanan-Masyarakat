# pelayanan-masyarakat

Judul project : Layanan Masyarkat

Deskripsi singkat : Portal digital layanan publik cerdas yang menghadirkan fitur pelaporan mandiri warga, pelacakan status, dan asisten AI interaktif untuk pelayanan masyarakat yang transparan dan inklusif.

Tech stack : html,css,js,Bootstrap 5

Progress saat ini : Progress saat ini: Aplikasi sudah memiliki halaman landing page yang responsif, sistem autentikasi dasar, serta modul pelaporan informasi warga.

Cara menjalanan project : 1. Clone Repository Buka terminal/command prompt dan jalankan perintah berikut:

git clone [https://github.com/izdiharasnasyukri/pelayanan-masyarakat.git](https://github.com/izdiharasnasyukri/pelayanan-masyarakat.git)
Masuk ke Direktori Proyek

Bash
cd Pelayanan-Masyarakat
Instalasi : Tidak ada proses instalasi khusus (tanpa npm install), karena proyek ini dibangun menggunakan HTML,
CSS, Bootstrap, dan JavaScript murni.


Jalankan Proyek
Menggunakan VS Code
Buka folder proyek di Visual Studio Code.

Pastikan ekstensi Live Server sudah terpasang.

Klik kanan pada file index.html lalu pilih "Open with Live Server"
